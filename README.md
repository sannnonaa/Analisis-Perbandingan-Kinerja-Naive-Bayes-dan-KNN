This repository features an automated Python-based classification system for maritime administrative documents. The system integrates a complete end-to-end pipeline comprising hybrid text extraction (PyMuPDF & Tesseract OCR with adaptive thresholding), 7-stage NLP preprocessing (case folding, cleaning, tokenization, domain abbreviation normalization, stopword removal, proper noun removal, and Sastrawi stemming), and TF-IDF feature extraction ($n\text{-gram } 1,2$ with sublinear scaling). Utilizing Machine Learning models (Multinomial Naïve Bayes and KNN with Cosine Similarity metric), the system categorizes shipping paperwork into four operational classes: Perbaikan (Repairs), Perizinan (Permits), Persetujuan (Approvals), and Sertifikat (Certificates).
